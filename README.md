# QTranslate AI Hub 🚀

> **Универсальный ИИ-шлюз и оркестратор сервисов перевода, распознавания текста (OCR) и нейро-озвучки (TTS) для QTranslate и Windows.**

---

## 📖 О проекте

**QTranslate AI Hub** — это высокопроизводительный локальный шлюз и настольное приложение для Windows (7 / 8 / 10 / 11), расширяющее возможности популярного переводчика [QTranslate](https://quest-app.appspot.com/) современными нейросетевыми моделями (LLM), инструментами браузерной автоматизации, офлайн-OCR и студийной озвучкой текста.

### Ключевые преимущества:
- ⚡ **0 внешних зависимостей (Zero `pip` dependencies)**: Весь проект написан на чистом стандартном Python 3.8+ (`urllib`, `ctypes`, `socket`, `ssl`, `json`, `tkinter`). Установка сторонних Python-пакетов через `pip` не требуется.
- 🧩 **Глубокая интеграция с QTranslate**: Полноценный набор скриптов в каталоге `Services/` для добавления нейросетей непосредственно в интерфейс и всплывающее окно QTranslate.
- 🌐 **CDP-мост к веб-версиям нейросетей**: Поддержка Google AI Mode, ChatGPT Web, DeepL Web через прямое управление браузером (Supermium / Chromium) по протоколу Chrome DevTools Protocol (CDP) без платных API-ключей.
- 🛡️ **Обход региональных ограничений (DoH / DNS-over-HTTPS)**: Встроенная поддержка Comss.one SmartDNS и кастомных DoH-резолверов для прямого доступа к API без стороннего VPN.
- 🔍 **Автономный веб-поиск**: Интеграция с DuckDuckGo и парсером веб-страниц для проверки фактов, сленга и терминов прямо во время перевода.
- 👁️ **Офлайн OCR (PP-OCRv5 / PP-OCRv6)**: Сверхбыстрое распознавание текста на экране через MNN runtime (`rt_ocr.exe`) с инструментом экранного выделения (Screen Snipper).
- 🎙️ **Нейро-озвучка Edge-TTS**: Чистая WebSocket-реализация протокола Microsoft Edge Speech без сторонних библиотек, с выводом через Windows MCI (`winmm.dll`).
- 📚 **Глоссарий и контекстные пресеты**: Динамическая подстановка терминов и готовые системные промпты для академического, программного, игрового и литературного стилей перевода.

### Основные компоненты репозитория

| Путь | Назначение |
|---|---|
| `data/main.py` | Точка входа приложения: системный Mutex (`Global\QTranslate_AI_Hub_SingleInstance_Mutex`), инициализация подсистем, GUI и трея. |
| `Services/` | Клиентские модули для QTranslate: `Common.js` и конфигурации сервисов (`ChatGPT_Web`, `Google_AI`, `Gemini_Family`, `Qwen`, `OpenAI_120B` и др.). |
| `data/core/server.py` | Встроенный HTTP-сервер (порт `8080`), диспетчеризующий запросы от QTranslate к соответствующим плагинам сервисов. |
| `data/core/cdp_client.py` | Клиент Chrome DevTools Protocol для управления Chromium / Supermium (защита от засыпания вкладок, навигация, извлечение DOM). |
| `data/core/win_api.py` | Низкоуровневые WinAPI-функции (буфер обмена, горячие клавиши, фокус окон, Mutex, MCI-аудио). |
| `data/core/api_config.py` | Загрузка и сохранение конфигурации моделей, эндпоинтов, токенов и DoH-настроек из `data/api_keys.ini`. |
| `data/services/` | Бэкенд-реализации сервисов (CDP-парсеры и прямые API-клиенты). |
| `data/ocr/` | Офлайн-движок OCR на базе `rt_ocr.exe` (MNN PaddleOCR v5/v6) и экранный захват (`screen_snipper.py`). |
| `data/tts/` | Студийная озвучка через Microsoft Edge TTS по прямому WebSocket-каналу с поддержкой голосов Svetlana, Dmitry, Jenny и др. |
| `data/batch/` | Пакетный перевод документов с защитой программного кода, тегов и разбиением на контекстные чанки (`chunker.py`, `code_protector.py`). |
| `data/dictionary/` | Движок словарей и терминологических замен (`glossary_engine.py`, `glossary.txt`). |
| `data/presets/` | Пресеты системных инструкций под разные стили (игры, код, академический, художественный). |
| `data/gui/` | Графический интерфейс на Tkinter с темами оформления (Nord, Dark, Light) и поддержкой 14 языков локализации. |

## 💻 Системные требования

- **Операционная система**: Windows 7 SP1, Windows 8 / 8.1, Windows 10, Windows 11 (поддерживаются как x86, так и x64).
- **Python**: Версия **3.8 или выше** (убедитесь, что Python добавлен в системную переменную `PATH`).
- **Сторонние Python-библиотеки**: **Не требуются** (0 pip dependencies).
- **QTranslate** *(рекомендуется)*: Установленный или портативный QTranslate 6.x для работы глобальных шорткатов.
- **Браузер для CDP-режима** *(опционально)*: Портативный Supermium или Google Chrome с флагом `--remote-debugging-port=9222`.

## 🚀 Установка и быстрый старт

### Шаг 1. Клонирование или скачивание

Склонируйте репозиторий в удобную папку на компьютере:
```bash
git clone https://github.com/MAX-EMELKIN/AI-Hub.git
cd AI-Hub
```

### Шаг 2. Размещение вспомогательных компонентов

Рекомендуемая структура размещения:
```
AI-Hub/
├── QTranslate.exe         <-- (опционально) поместите QTranslate в корень или рядом
├── browser/               <-- (для веб-сервисов) Supermium / Chromium Portable
│   └── engine/
│       └── chrome.exe
├── Services/              <-- JS-плагины для QTranslate
├── data/
│   ├── main.py
│   ├── config.ini
│   └── api_keys.ini
```

### Шаг 3. Подключение сервисов к QTranslate

1. Откройте папку установки QTranslate (например, `C:\Program Files (x86)\QTranslate` или вашу портативную папку).
2. Скопируйте содержимое папки `Services/` из репозитория в папку `Services/` программы QTranslate.
3. Перезапустите QTranslate — в списке сервисов появятся:
   - `Google AI (Browser)`
   - `ChatGPT Web`
   - `DeepL Web`
   - `Gemini Family`
   - `Qwen 3.8 Flash / Max / Plus / Turbo`
   - `OpenAI 120B`
   - `DeepSeek V4`
   - и другие.

### Шаг 4. Настройка API-ключей (для API-сервисов)

Если вы планируете использовать прямые API (Google Gemini, Cloudflare, OpenRouter, Qwen DashScope):
1. Откройте файл `data/api_keys.ini` в текстовом редакторе или настройте ключи через графический интерфейс AI Hub.
2. Заполните поля `api_key` для нужных сервисов (например, в секции `[gemini_family]` или `[openai_120b]`).

### Шаг 5. Запуск приложения

Запустите оркестратор:
```bash
python data/main.py
```
Приложение:
- Проверит и захватит системный Mutex для исключения дублирования процессов.
- Запустит локальный HTTP-сервер на `http://127.0.0.1:8080`.
- При необходимости автоматически запустит `QTranslate.exe`.
- Свернется в системный трей (иконка рядом с часами).

## ⚙️ Конфигурация

### Основные настройки (`data/config.ini`)

- `[GENERAL]`
  - `AutoLaunchQTranslate = 1` — автоматический запуск QTranslate при старте AI Hub.
  - `ServerPort = 8080` — локальный порт HTTP-сервера.
  - `UILanguage = ru` — язык интерфейса (доступно 14 языков: `ru`, `en`, `de`, `zh`, `fr`, `es` и др.).
  - `StartMinimized = 1` — запуск приложения сразу свернутым в системный трей.
- `[BROWSER]`
  - `UsePortable = 1` — использование портативного браузера из папки `browser/`.
  - `CdpPort = 9222` — порт удаленной отладки Chrome DevTools Protocol.
  - `AutoDismissPopups = 1` — автоматическое закрытие всплывающих баннеров и диалогов согласия.
- `[HOTKEYS]`
  - `ocr = Alt+W` — горячая клавиша быстрого вызова экранного OCR.
  - `tts = Alt+E` — горячая клавиша нейро-озвучки выделенного текста.
- `[DICTIONARY]`
  - `enabled = 1` — использование глоссария терминов (`data/dictionary/glossary.txt`).
- `[LOGGING]`
  - `ShowConsole = 1` — отображение консоли отладки.
  - `LogToFile = 1` — ведение подробного журнала в `data/logs/hub_debug.log`.

## ⌨️ Горячие клавиши по умолчанию

| Сочетание | Функция |
|---|---|
| `Alt + W` | **Экранный OCR**: Запуск экранного снайпера, моментальное распознавание выделенной области и передача текста в QTranslate / перевод. |
| `Alt + E` | **Нейро-озвучка (TTS)**: Перехват выделенного текста в любом приложении Windows и воспроизведение голосом Microsoft Edge Neural. |
| `F1` / `Двойной Ctrl` | Стандартный вызов окна перевода QTranslate (настраивается в параметрах QTranslate). |

## 🛠️ Устранение неполадок (FAQ)

**В: Порт 8080 занят другим приложением.**  
О: Измените `ServerPort = 8080` в `data/config.ini` на свободный порт (например, `8085`), и обновите переменную `LOCAL_URL` в `Services/Common.js` и нужных сервисах `Services/*/service.js`.

**В: Веб-сервисы (Google AI, ChatGPT Web) возвращают ошибку подключения к браузеру.**  
О: Убедитесь, что Chromium/Supermium запускается с параметром `--remote-debugging-port=9222`, либо поместите портативную сборку Supermium в папку `browser/engine/`.

**В: Блокировка доступа к зарубежным API (OpenAI, Gemini).**  
О: В `data/api_keys.ini` в секции сервиса установите `connection_mode = doh` и выберите `doh_preset = Comss.one (SmartDNS / РФ обход)`. AI Hub будет резолвить IP-адреса через защищенный DoH-канал.

**В: Не запускается второй экземпляр программы.**  
О: В программе работает системный мьютекс `Global\QTranslate_AI_Hub_SingleInstance_Mutex`. Проверьте системный трей (иконка в области уведомлений Windows) или закройте зависший процесс через Диспетчер задач.
